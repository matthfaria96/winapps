# RubinOT na VM (histórico)

Nota histórica de quando o caminho considerado era uma VM com Windows. Hoje o RubinOT
roda no motor do WinApps — ver [RUBINOT-21.md](RUBINOT-21.md).

Para uma VM, o único item deste repositório que ainda faz sentido é o prefixo pronto em
`/Volumes/WinAppsDev/prefixes/rubinot` (mesmos componentes do WinApps).
